Website Accessibility in the UK: What Small Businesses Should Build In

Website accessibility guidance for UK small businesses covering WCAG 2.2 principles, contrast, keyboard navigation, forms, images, motion and practical testing.

Accessibility is a design and quality issue, not a plugin. A website is more usable when people can navigate it with a keyboard, read it at high zoom, understand form errors and use it without being forced through unnecessary motion or visual complexity.

Know the regulatory context

UK public-sector websites and apps are expected to meet WCAG 2.2 AA and publish accessibility statements. Private businesses should also consider accessibility duties under equality law and, regardless of legal scope, accessible design improves usability for a wider audience.

Start with contrast and type

Use strong colour contrast for text and controls. Do not rely on colour alone to communicate status. Keep body type readable and allow the browser to zoom without breaking the layout.

Test keyboard navigation

Every interactive element should be reachable in a sensible order without a mouse. Focus indicators need to be visible, menus should not trap users and custom controls need proper semantics.

Make forms understandable

Use real labels, correct input types, clear required-state communication and specific error messages. Do not use placeholder text as the only label.

Respect reduced motion

Large parallax effects, auto-playing motion and endless marquees can make a site difficult for some users. Support the browser’s reduced-motion preference and keep animation purposeful.
